# Phase II Oncology Clinical Data Management Portfolio

This project simulates end-to-end clinical data management activities for a Phase II melanoma immunotherapy clinical trial.

## Tools
- REDCap
- Power BI
- Excel

## Skills Demonstrated
- eCRF/database design
- Longitudinal clinical trial setup
- Branching logic
- Edit checks
- Data validation
- Query management
- Adverse event review
- RECIST tumor assessment
- Clinical data cleaning
- Power BI dashboard development
- SQL analysis

## Study Overview
- Phase II oncology study
- 20 simulated participants
- Screening through Week 24
- Safety follow-up
- Synthetic data only
